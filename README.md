# shaw-spell data

What the Shaw-Spell editor derives and commits here: the Shavian lexicon and
the editorial patches it was built from.

- `readlex.json` — the lexicon, 61,222 entries across 115,530 senses.
- `readlex-affixes.json` — the bound forms (prefixes, suffixes, clitics), same
  schema, kept apart so nothing reading the lexicon mistakes a fragment for a
  word. What it holds, and the rules for attaching affixes and reproducing
  regular inflections, are in [`docs/affixes.md`](docs/affixes.md).
- `patches/patches.jsonl` — the editorial patch store. Each line records one
  decision, its author and its reasoning.

`readlex.json` is derived by applying the patch store to upstream ReadLex.
[`shaw-spell-editor`](https://github.com/cozmic72/shaw-spell-editor) is the sole
publisher — the only thing that derives it — and commits it here;
`src/tools/apply_patches.py` there does the same job offline. Nothing pulls from
this repository automatically: a consumer takes the data when someone moves
it.

Mounted as a submodule at `data/` by the projects that read it. Nothing here is
generated by a build: the pipeline's intermediates, trained models and site
artefacts live outside git, because versioning a gigabyte of regenerable input
is what made an earlier incarnation of this repository impossible to clone.
