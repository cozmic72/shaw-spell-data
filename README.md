# shaw-spell data

What the Shaw-Spell editor publishes: the Shavian lexicon and the editorial
patches it was built from.

- `readlex.json` — the published lexicon, 61,222 entries across 115,530 senses.
- `patches/patches.jsonl` — the editorial patch store. Each line records one
  decision, its author and its reasoning.

`readlex.json` is derived by applying the patch store to upstream ReadLex.
[`shaw-spell-editor`](https://github.com/cozmic72/shaw-spell-editor) publishes it;
`src/tools/apply_patches.py` there does the same job offline.

Mounted as a submodule at `data/` by the projects that read it. Nothing here is
generated by a build: the pipeline's intermediates, trained models and site
artefacts live outside git, because versioning a gigabyte of regenerable input
is what made an earlier incarnation of this repository impossible to clone.
